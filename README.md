# GitHub Basic - TuanND

## 1. Giới thiệu
- PIC: TuanND
- Mục tiêu: Tìm hiểu và thực hành Git, GitHub.

## 2. Mục tiêu học GitHub
- Hiểu cách Git quản lý phiên bản source code.
- Biết cách sử dụng repository.
- Thành thạo và nắm vững branch, merge trong Git.
- Biết cách làm việc với GitHub.

## 3. Git Commands đã thực hành

| Command | Ý nghĩa |
|---|---|
| git init | Khởi tạo repository |
| git add | Đưa file vào staging area |
| git commit | Lưu phiên bản |
| git status | Kiểm tra trạng thái |
| git log | Xem lịch sử commit |
| git push | Đẩy commit lên remote |

## 4. Git Branch

- Branch giúp phát triển tính năng độc lập.
- Có thể tạo nhiều branch trong một repository.
- Merge giúp kết hợp thay đổi giữa các branch.
